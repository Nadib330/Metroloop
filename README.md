A music client for YouTube Music, based on Metrolist 13.

MetroLoop is an independently developed project built on the Metrolist 13 codebase. It follows its own development direction and does not aim to synchronize with the upstream project.

## Features

- YouTube Music playback
- Lyrics support
- Lyrics translation using Google Translate
- Music library and playlist features inherited from the Metrolist 13 foundation

> The feature list is being refined as MetroLoop development progresses. Availability may vary by build.

## Project direction

MetroLoop is developed independently. Its focus includes:

- Cleaning up legacy and unnecessary code inherited from the base project.
- Removing obsolete upstream update-related implementation.
- Keeping the functionality that remains useful to MetroLoop.
- Making selected replacements and changes independently of upstream development.
